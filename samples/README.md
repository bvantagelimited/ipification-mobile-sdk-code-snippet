# Runnable sample projects

- [`android/process-binding-ip-check`](android/process-binding-ip-check/README.md): verify the
  public IP before Android process binding, while the process is forced to cellular, and after
  normal routing is restored. The app also includes WebView and Custom Tab tests.

Small source files intended to be copied into an existing application remain under
[`../examples`](../examples/README.md).
